# Demo asset licenses

`HallOfTheMountainKing.mid` comes from Mutopia Project item 1888. Its source
declares both the composition and typesetting public domain:
https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1888

The generated WAV uses MuseScore General, whose soundfont and samples are
licensed under the MIT license:
https://musescore.org/en/handbook/3/soundfonts-and-sfz-files

The soundfont itself is not stored in this repository. The release pipeline
downloads it from MuseScore and renders the MIDI with FluidSynth.
