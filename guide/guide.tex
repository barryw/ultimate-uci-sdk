\section*{Introduction}
\addcontentsline{toc}{chapter}{Introduction}

The \sdk{} gives a C64 program one API for the Ultimate command interface and
for the two supported features that use direct hardware registers: REU transfers
and Ultimate~64 turbo control. The language chapters cover every public call.

\evidence{\cmd{include/ultimate.h}; \cmd{include/uci.h};
\cmd{tools/test\_registers.py}}

The implementation is 6502 assembly. cc65 links it as a library; ca65 callers
use its assembly ABI; BASIC reaches a banked build through a wedge; other
toolchains call the same object code through a standalone jump-table binary.

\evidence{\cmd{src/uci/sources.mk}; \cmd{bindings/cc65/Makefile};
\cmd{src/basic/Makefile}; \cmd{bindings/blob/Makefile}}

\subsection*{How to read this}

Chapter~1 covers setup and chooses a binding. Chapters~2 to~5 document the
binding-specific rules and every public entry point. Each example says what
feature it demonstrates; the appendix holds the result-code table.

\subsection*{A word about the name}

The library is called the Ultimate SDK rather than the Ultimate~64 SDK because
the command interface predates the Ultimate~64. Programs probe targets with
\cmd{ultimate\_detect()} and test the REU and turbo registers separately.

\evidence{\cmd{docs/compatibility.md}; \cmd{include/ultimate.h}}
