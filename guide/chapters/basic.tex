\section{Two Ways To Install The Same Wedge}

Chapter~1 shows the \cmd{uci.prg} installation. Its loader copies the SDK under
BASIC ROM at \cmd{\$A000} and the wedge to RAM at \cmd{\$C000}, installs four
BASIC vectors, then performs \bas{new}. The normal BASIC program area remains
available.

The \cmd{uci.crt} build carries the same runtime bytes in an 8K cartridge. It
autostarts and its warm-start vector reinstalls the wedge after reset. While the
cartridge remains mapped at \cmd{\$8000--\$9FFF}, BASIC's program area is 8K
smaller.

Both builds contain the same wedge; only their loaders differ.

\evidence{\cmd{src/basic/uci-wedge.cfg}; \cmd{src/basic/uci-cart.cfg};
\cmd{src/basic/loader.s}; \cmd{src/basic/cart.s};
\cmd{tools/test\_make\_crt.py}}

\begin{warning}
The wedge owns BASIC's tokenise, list, statement-dispatch and expression
vectors and does not chain previous owners. Do not combine it with another
extension that needs any of those vectors unless that combination provides an
explicit compatibility layer.
\end{warning}

\section{Every BASIC Keyword By Example}

The wedge exposes twenty-three keywords. This section uses every one. Services
without a dedicated keyword remain available through the raw \bas{uci}
statement. Output below is from a representative successful run; model names,
times, directory entries and REU size depend on the machine. When a result is
fixed, it appears directly after \bas{run} in the same screen.

\subsection*{Run a command and inspect every result}

\begin{screen}
10 UCI UCTRL,1\\
20 PRINT "RESULT";UERR;" DEVICE";UDEV;" BYTES";ULEN\\
30 PRINT "STATUS: ";UST\$\\
40 PRINT "DATA: ";UDAT\$\\
50 FOR I=0 TO ULEN-1:PRINT UBYTE(I);" ";:NEXT:PRINT\\
RUN\\
RESULT 0 DEVICE 0 BYTES 14\\
STATUS: 00,OK\\
DATA: CONTROL TARGET\\
67 79 78 84 82 79 76 32 84 65 82 71 69 84\\
READY.
\end{screen}

\bas{uci uctrl,1} asks the control target to identify itself. \bas{uerr} is the
SDK result, \bas{udev} is the target's raw status number, and \bas{ulen} is the
retained reply length. \bas{ust\$} returns the status text, \bas{udat\$} returns
up to 255 reply bytes as a string, and \bas{ubyte(n)} returns one retained byte
or zero when \bas{n} is past the end.

\subsection*{Use every target constant}

\begin{screen}
10 PRINT UDOS1,UDOS2,UNET,UCTRL,UIEC,UHTTP\\
RUN\\
1  2  3  4  5  6\\
READY.
\end{screen}

The printed values are 1 through 6: the two DOS instances, network, control,
SoftwareIEC and HTTP targets. Use these names as the first argument to
\bas{uci}; do not copy their numeric values into programs.

\subsection*{Send a raw command with and without an optional argument}

\begin{screen}
10 UCI UDOS1,38: PRINT UDAT\$\\
20 UCI UDOS1,38,0: PRINT UDAT\$\\
30 UCI UCTRL,40: PRINT UDAT\$\\
40 UCI UCTRL,40,0: PRINT UDAT\$\\
50 IF UERR THEN PRINT "COMMAND FAILED";UDEV
\end{screen}

Command 38 is \cmd{DOS\_CMD\_GET\_TIME}. Line~10 omits its optional format
byte; line~20 supplies it explicitly. Command 40 is
\cmd{CTRL\_CMD\_GET\_HWINFO}; the firmware documentation marks it deprecated.
Lines~30 and 40 show its omitted and explicit model selector only to make the
wire format clear. Both commands default an omitted argument to zero. A number
normally contributes one byte; known wide arguments are widened automatically.

\Needspace{30\baselineskip}
\subsection*{Read SID addresses through deprecated HWINFO}

\begin{screen}
5 REM LEGACY: HWINFO IS DEPRECATED\\
10 UCI UCTRL,40,1\\
20 IF UERR THEN PRINT "SID INFO FAILED";UERR:END\\
30 PRINT "SID COUNT";UBYTE(0)\\
40 FOR I=0 TO UBYTE(0)-1\\
50 A=1+5*I\\
60 PRINT "SID";I+1;UBYTE(A)+256*UBYTE(A+1)\\
70 NEXT\\
RUN\\
SID COUNT 4\\
SID 1  54272\\
SID 2  54272\\
SID 3  54272\\
SID 4  54272\\
READY.
\end{screen}

The explicit selector 1 requests SID information through a command the
firmware documentation marks deprecated. Firmware still implements it but may
remove it, and no replacement C64-side UCI command is currently published.
Byte zero is the record
count. Each five-byte record starts with the primary address, least-significant
byte first; line~60 reconstructs that address. Decimal 54272 is \cmd{\$D400}.
The following two bytes are the optional secondary address and the fifth is a
raw type value, not a 6581 or 8580 model identifier.

\evidence{\cmd{src/basic/dispatch.s}; \cmd{tests/hardware/basictest.py};
\cmd{software/io/command\_interface/control\_target.cc}}

\subsection*{Force raw argument widths}

\begin{screen}
10 UCI UDOS1,240,UW(4660),UL(65536)\\
20 FOR I=0 TO ULEN-1:PRINT UBYTE(I);" ";:NEXT:PRINT\\
RUN\\
1 240 52 18 0 0 1 0\\
READY.
\end{screen}

Command 240 echoes the target byte, command byte and arguments. The leading
1 and 240 confirm the framing. \bas{uw(4660)} sends 52,18 and
\bas{ul(65536)} sends 0,0,1,0: both are little-endian. These overrides are for
commands newer than the wedge's shape table or deliberately raw byte layouts.

\subsection*{Abort an unfinished exchange}

\begin{screen}
UCI:PRINT UERR\\
0\\
READY.
\end{screen}

A bare \bas{uci} sends no command. It aborts any exchange left unfinished by a
stopped program and returns the interface to idle; \bas{uerr} reports whether
the recovery succeeded.

\subsection*{Set and read turbo}

\begin{screen}
10 UTURBO 3: IF UERR THEN PRINT "TURBO UNAVAILABLE":END\\
20 PRINT "SPEED INDEX";UTURBO\\
RUN\\
SPEED INDEX 3\\
READY.
\end{screen}

The statement form sets an index; the function form reads it. Portable indices
0 through 3 select 1, 2, 3 and 4MHz. A read of 255 means the turbo registers are
unavailable.

\subsection*{Load a PRG with and without the optional address}

\begin{screen}
10 ULOAD "GAME.PRG": IF UERR THEN END\\
20 ULOAD "FONT.PRG",49152: IF UERR THEN END
\end{screen}

Line~10 consumes the PRG's two-byte header and loads at the address stored
there. Line~20 still consumes the header but loads the remaining bytes at
49152. Dedicated filename keywords copy at most 63 bytes and add a terminator.

\subsection*{Load and save raw memory}

\begin{screen}
10 UBLOAD "FONT.BIN",49152,2048: IF UERR THEN END\\
20 USAVE "SCREEN.BIN",1024,1000: IF UERR THEN END
\end{screen}

\bas{ubload} reads at most 2048 raw bytes into address 49152; it consumes no
header. \bas{usave} replaces \cmd{SCREEN.BIN} with 1000 bytes beginning at C64
address 1024.

\Needspace{12\baselineskip}
\subsection*{List the current directory}

\begin{screen}
UDIR
\end{screen}

\bas{udir} takes no parameters. It opens the current Ultimate directory,
prints every entry and leaves \bas{uerr} at zero when the normal end marker is
reached.

\subsection*{Copy memory to and from the REU}

\begin{screen}
10 R=UREU:PRINT "REU BANKS";R:IF R=0 THEN END\\
20 USTASH 1024,0,1000:IF UERR THEN END\\
30 PRINT CHR\$(147)\\
40 UFETCH 1024,0,1000:IF UERR THEN END
\end{screen}

\bas{ureu} returns the expansion size in 64K banks. \bas{ustash} copies the
1000-byte C64 text screen to REU address zero; \bas{ufetch} copies it back. The
REU address is 24 bits. Keep the address plus length within \bas{ureu} times
65536; a DMA length of zero means 65536 bytes.

\section{BASIC-specific Limits}

\Needspace{12\baselineskip}
\subsection*{A statement extension cannot follow THEN directly}

BASIC V2's \bas{if} path enters the ROM statement dispatcher instead of the
wedge vector, so this is rejected:

\begin{screen}
10 IF X = 1 THEN ULOAD "GAME.PRG"\\
RUN\\
?SYNTAX ERROR IN 10\\
READY.
\end{screen}

Branch to a line containing the extension statement:

\begin{screen}
10 IF X = 1 THEN 100\\
20 END\\
100 ULOAD "GAME.PRG"
\end{screen}

This demonstrates the workaround. Extension functions are unaffected, so
\bas{if uerr then 100} remains valid.

\subsection*{Reply storage is finite}

The wedge retains 256 reply bytes. \bas{udat\$} can expose only 255 because
that is BASIC's maximum string length; \bas{ubyte(0)} through
\bas{ubyte(255)} can inspect the retained bytes individually. A longer raw
reply sets \bas{uerr} to \cmd{ULTIMATE\_ERR\_TRUNCATED}.

\evidence{\cmd{src/basic/dispatch.s}; \cmd{tests/emulator/basic.suite}}
